# 安装程序视觉原型

这是安装器的本地网页版视觉评审稿。其目标是先确认视觉、信息层级和动画节奏，再迁移到 WPF 安装向导，避免反复编译安装程序。

## 预览

从仓库根目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/installer/web-prototype/
```

原型支持：

- 从欢迎页按顺序演示到安装完成；
- 环境检查逐项动画；
- 安装进度和阶段动画；
- 系统“减少动画”偏好；
- 桌面、窄屏和平板宽度适配。

## 窗口圆角策略

原型只保留一个外层窗口轮廓：

- 外层使用 `border-radius` 和 `overflow: hidden` 统一裁切；
- 所有标题栏、侧栏和底栏都在该裁切层内部；
- 不叠加第二套直角系统边框或未裁切的子元素背景；
- 阴影绘制在窗口外部，不参与内部边缘轮廓。

视觉确认后，WPF 实装应采用同样原则：选择一种窗口轮廓方案，不同时保留透明圆角窗口和系统矩形边框。
