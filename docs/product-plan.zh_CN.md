# 小猫助手产品与实现规划

## 产品流程

1. 待机页按下 OK 后立即录音，保持按住时持续录音。
2. 松开 OK 后结束录音，App 将已经接收的音频提交给阿里云 ASR。
3. 转写文本返回设备，由用户检查。
4. OK 确认后才发送给阿里云大模型；UP 重新录音；DOWN 取消。
5. AI 回复以增量文本返回设备并流式显示。
6. App 保存连续上下文；手动新建或空闲超过 30 分钟后开启新会话。

## 职责边界

### 固件

- 初始化显示、按键、麦克风、电池和 BLE。
- 分块采集 16 kHz、16 bit、单声道 PCM，禁止缓存完整录音。
- 将音频编码为低开销 IMA-ADPCM 帧并通过 BLE 通知发送。
- 管理录音、转写确认、等待回复、流式回答和错误恢复状态。
- 显示独立设计的像素小猫界面、电量、连接状态和文字。
- 不持有 API Key、聊天历史或云服务配置。

### 安卓 App

- 扫描、配对并连接设备，协商 MTU，订阅控制和音频通知。
- 校验音频序号，解码 IMA-ADPCM，生成 16 kHz 单声道 WAV。
- 使用一个阿里云百炼 API Key 调用 ASR 和大模型。
- 将转写结果和 AI 增量文本分片回传设备。
- 本地保存会话、消息、模型配置和最后活动时间。
- 使用 Android Keystore 保护 API Key，不在日志或 BLE 包中暴露密钥。

## 页面与按键

| 状态 | 主要显示 | UP | DOWN | OK |
| --- | --- | --- | --- | --- |
| 未连接 | 小猫与连接提示 | - | - | 重启广播 |
| 待机 | 小猫、连接/电量、最近回复 | 上翻 | 下翻 | 按下录音，松开结束 |
| 录音 | 时长、音量、小猫聆听 | - | - | 保持录音，松开结束 |
| 转写中 | 小猫思考、进度提示 | - | 取消 | - |
| 待确认 | 转写文本 | 重新录音 | 取消 | 确认发送 |
| AI 思考 | 已确认问题与等待提示 | - | 取消本轮 | - |
| 回复中/完成 | AI 回复正文 | 上翻 | 下翻 | 再次按住可提问 |

待机或回答页长按 UP 直接开启新会话，避免假设三键 ADC 能识别组合按键。

## 设备状态机

```text
DISCONNECTED -> IDLE -> RECORDING -> TRANSCRIBING
             -> TRANSCRIPT_REVIEW -> AI_WAITING
             -> AI_STREAMING -> ANSWER_READY
```

任何联网阶段都可进入 `ERROR`。BLE 断开会终止当前录音或请求，清理临时数据后进入 `DISCONNECTED`。

## 默认参数

- 单次录音上限：30 秒。
- 过短录音：小于 300 ms，不调用 ASR。
- 自动新会话：上一轮完成后空闲 30 分钟。
- 屏幕自动变暗：60 秒无操作；录音和回复期间暂停。
- 音频：16 kHz、16 bit、单声道、20 ms 一帧、IMA-ADPCM 4 bit。
- BLE：设备为 peripheral，手机为 central，单连接并要求加密绑定。
- 单条转写上限 2 KiB；设备保留的单条 AI 回复上限 12 KiB。

## 验收边界

自动检查覆盖纯状态机、协议分片、UTF-8 安全截断和 IMA-ADPCM 编解码。麦克风清晰度、BLE 实际吞吐、按键手感、中文字体覆盖、长文本排版、运行时内存和功耗必须在真机验证。
